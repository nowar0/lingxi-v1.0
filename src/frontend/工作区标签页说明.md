# 工作区标签页（历史 V0.3 说明）

本文是历史工作区行为记录，不是当前 V0.4 发布验收证明。当前目标为 `E:\AI agnet\零汐-V0.4-win64`；真实验收以本轮隔离测试、候选冻结后端和最终发布清单为准。

- 会话区支持新建、搜索、置顶、重命名、归档及收起。
- 聊天区保留会话草稿、消息、历史回退、附件、停止与重试等原有连接；工作回复改用连续正文，输入框固定在底部。
- 右侧通过“＋”添加上下文、任务、项目文件、更改差异、终端、Git / Worktree、SSH / SFTP、预算与验收。相同工具只打开一个标签，文件按完整路径区分。支持切换、关闭、收起、扩大和拖动宽度。
- 点击文件在新标签中只读预览；终端从同一个“＋”菜单打开，先预览具体命令和目录，再逐条确认执行。切换工具标签保留输入和已打开的工具表单。
- 关闭当前标签会选择相邻标签并迁移焦点；标签溢出时滚动至活动页。工具占满窄窗口时提供返回聊天入口，背景聊天不参与键盘聚焦。
- 每个会话使用独立组件生命周期，防止快速切换 A→B→A 时旧请求回填。改绑目录会清理旧文件预览、差异、终端输入和命令预览；从 Git / Worktree 改绑也会在离开工具时同步。

## 开始页、移动和完全收起（2026-10-28 补充）

按照用户补充的三张截图，右侧初始标签改为“开始”，以当前角色淡背景和三个大入口提供工作区文件、新建终端、浏览器。Ctrl + P、Ctrl + `、Ctrl + T 对应打开；浏览器复用已有专用浏览器控制接口。

每个标签可以拖到左侧或右侧窗格，也可以通过标签菜单移动。工作对话移到右侧时显示为“侧边聊天”。移动时保持同一内容实例，终端草稿、文件内容和 Git/SSH 工具不因换侧重新挂载。打开已在另一侧的工具会显示其所在窗格。

右侧边界可拖动调整宽度，继续向右拖动并松开可完全收起，记住展开宽度；动画沿用主导航的弹簧响应与阻尼。完全收起后顶部保留数字按钮，点击“已打开的标签页”列表可选回标签。空右窗格也能重新打开开始页。减少动态设置会跳过弹簧动画。
